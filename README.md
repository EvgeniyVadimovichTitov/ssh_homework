# Настройка протокола SSH

В данном документе представлена пошаговая последовательность выполнения заданий с 1 по 8 для настройки безопасного удаленного доступа по протоколу SSH.

---

## Задание 1. Базовое подключение к удаленному серверу

**Цель:** Проверить доступность сервера и выполнить первичное подключение по паролю.

```bash
# Подключение к удаленному серверу по его IP-адресу и имени пользователя
ssh user@server_ip
```
*После успешной проверки закройте сессию командной строки:*
```bash
exit
```

---

## Задание 2. Генерация пары SSH-ключей на клиенте

**Цель:** Создать криптографические ключи (приватный и публичный) для безопасной беспарольной аутентификации.

```bash
# Генерация RSA ключа длиной 4096 бит
# При запросах passphrase нажмите Enter (оставить пустым) для автоматического входа
ssh-keygen -t rsa -b 4096 -f ~/.ssh/id_rsa
```

---

## Задание 3. Копирование публичного ключа на удаленный сервер

**Цель:** Перенести публичный ключ на сервер в файл `~/.ssh/authorized_keys` для реализации авторизации по ключам.

```bash
# Копирование публичного ключа (потребуется один последний раз ввести пароль пользователя)
ssh-copy-id user@server_ip

# Проверка беспарольного входа (подключение должно пройти без запроса пароля)
ssh user@server_ip
```

---

## Задание 4. Создание алиасов в конфигурационном файле клиента

**Цель:** Упростить процесс подключения, настроив короткий псевдоним (алиас) хоста.

1. Откройте или создайте локальный файл конфигурации клиента:
```bash
nano ~/.ssh/config
```

2. Добавьте в файл следующие параметры конфигурации:
```text
Host myserver
    HostName server_ip
    User user
    IdentityFile ~/.ssh/id_rsa
```

3. Проверьте быстрое подключение с использованием созданного алиаса:
```bash
ssh myserver
```

## Задание 5. Изменение стандартного端口 SSH на сервере

**Цель:** Повысить безопасность сервера методом скрытия (Security through obscurity), изменив дефолтный порт 22.

*Все команды выполняются внутри сессии сервера:*

1. Откройте конфигурационный файл демона SSH:
```bash
sudo nano /etc/ssh/sshd_config
```

2. Найдите строку `#Port 22`, раскомментируйте её и задайте новый порт (например, `2222`):
```text
Port 2222
```

3. *(Опционально)* Если на сервере включен брандмауэр UFW, разрешите новый порт:
```bash
sudo ufw allow 2222/tcp
```

4. Перезапустите службу SSH для применения изменений:
```bash
sudo systemctl restart sshd
```

## Задание 6. Отключение аутентификации по паролю

**Цель:** Полностью исключить возможность подбора паролей (брутфорса) к серверу, оставив доступ только по SSH-ключам.

*Команды выполняются на стороне сервера:*

1. Откройте конфигурационный файл:
```bash
sudo nano /etc/ssh/sshd_config
```

2. Найдите и измените (или добавьте в конец файла) следующие директивы:
```text
PasswordAuthentication no
PubkeyAuthentication yes
```

3. Перезапустите службу SSH:
```bash
sudo systemctl restart sshd
```
*После выполнения команд завершите текущую сессию на сервере:*
```bash
exit
```

## Задание 7. Безопасный обмен файлами (SCP и SFTP)

**Цель:** Освоить утилиты для шифрованной передачи данных с учетом измененного порта подключения (`2222`).

### Вариант А: Использование утилиты SCP (Secure Copy)
```bash
# Копирование локального файла на удаленный сервер
scp -P 2222 ~/Documents/local_file.txt user@server_ip:/home/user/

# Копирование директории с удаленного сервера на локальную машину
scp -P 2222 -r user@server_ip:/home/user/remote_folder ~/Downloads/
```

### Вариант Б: Использование интерактивной утилиты SFTP
```bash
# Подключение к серверу по протоколу SFTP через кастомный порт
sftp -P 2222 user@server_ip

# Внутри интерактивной сессии SFTP:
# Отправить файл на сервер
put local_file.txt

# Скачать файл с сервера
get remote_file.txt

# Выйти из интерактивного режима
exit
```

## Задание 8. Организация SSH-туннеля (Проброс портов)

**Цель:** Настроить безопасный туннель для перенаправления сетевого трафика. В примере ниже настраивается локальный проброс портов (Local Port Forwarding).

```bash
# Проброс порта 8080 удаленного сервера на локальный порт 9090 вашего компьютера
# Флаг -p указывает порт SSH, -L задает туннель, а -N запрещает выполнение удаленных команд
ssh -p 2222 -L 9090:127.0.0.1:8080 user@server_ip -N
```
*Для закрытия и уничтожения SSH-туннеля нажмите сочетание клавиш `Ctrl + C` в окне терминала.*
